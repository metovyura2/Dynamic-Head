# Screenshots

Place repository screenshots and demo GIFs in this folder and reference them from
`README.md` / `README.ru.md`.

Suggested files:

| File | Description |
|------|-------------|
| `tray-menu.png` | The tray context menu (toggle + settings entries). |
| `settings.png` | The settings window with two devices selected. |
| `demo.gif` | A short GIF showing the one-click toggle. |

Example Markdown usage in the READMEs:

```markdown
![Tray menu](docs/screenshots/tray-menu.png)
![Settings window](docs/screenshots/settings.png)
```
