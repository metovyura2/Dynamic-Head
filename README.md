# Dynamic-Head

Мини-программа для Windows: иконка в системном трее с **одним переключателем** между двумя
устройствами вывода звука — например, «Колонки» ↔ «Наушники». Переключение — одним кликом.

## Возможности

- **Один тумблер в трее** — левый клик по иконке мгновенно меняет устройство вывода.
- **Пункт меню** «Переключить на «…»» — то же самое из контекстного меню.
- **Две разные иконки**: синяя (первое устройство, «колонки») и зелёная (второе, «наушники») —
  текущее состояние видно сразу.
- **Окно настроек**: выбрать любые два активных устройства вывода и задать им свои подписи.
- **Автозапуск при входе** (галочка в меню трея, пишется в `HKCU\...\Run`).
- Настройки хранятся в `config.json` рядом с программой.
- Переключение применяется ко всем ролям звука (обычные приложения, мультимедиа, связь).
- Если устройство отключено — программа ищет его по имени и предупреждает, если не нашла.

## Требования

- Windows 10 / 11, x64.
- **.NET 8 Desktop Runtime** ([скачать](https://dotnet.microsoft.com/download/dotnet/8.0)) —
  для запуска готовой сборки.
- Для сборки из исходников — **.NET SDK 8**. На этой машине он установлен в **`D:\dotnet`**
  и добавлен в пользовательский `PATH` (перезапусти терминал, чтобы `dotnet` заработал).

## Сборка из исходников

```powershell
# Скриптом (рекомендуется)
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1

# Или вручную
& 'D:\dotnet\dotnet.exe' restore .\src\DynamicHead\DynamicHead.csproj
& 'D:\dotnet\dotnet.exe' build   .\src\DynamicHead\DynamicHead.csproj -c Release
& 'D:\dotnet\dotnet.exe' publish .\src\DynamicHead\DynamicHead.csproj -c Release -r win-x64 --self-contained false -o .\dist
```

После публикации в `dist\` будет `DynamicHead.exe`, папка `assets\` с иконками и библиотеки NAudio.

> SDK стоит на диске D, потому что официальный установщик `.exe` жёстко ставит его на C:
> (переменная `DOTNETHOME` — non-overridable). Обход — скрипт `dotnet-install.ps1`
> с параметром `-InstallDir D:\dotnet`.

## Использование

1. Запусти `DynamicHead.exe`. При первом запуске сразу откроется окно настроек.
2. Выбери **Устройство 1** (например, колонки) и **Устройство 2** (например, наушники).
   Справа можно поменять подписи, которые будут видны в меню трея.
3. Нажми **Сохранить**. Окно можно закрыть — программа продолжает работать в трее.
4. **Левый клик** по иконке — переключение. **Правый клик** — меню:
   - `Переключить на «…»` — сменить устройство;
   - `Настройки…` — открыть окно настроек (также по двойному клику);
   - `Обновить список устройств` — синхронизировать состояние с системой;
   - `Автозапуск при входе` — включить/выключить;
   - `Выход` — завершить программу.

## Настройки (`config.json`)

```json
{
  "DeviceAId": "{0.0.0.00000000}.{...}",
  "DeviceAName": "Колонки (Realtek High Definition Audio)",
  "DeviceBId": "{0.0.0.00000000}.{...}",
  "DeviceBName": "Наушники (USB Audio)",
  "LabelA": "Колонки",
  "LabelB": "Наушники",
  "RunAtStartup": false,
  "ActiveSlot": "A"
}
```

## Горячих клавиш нет

Управление только кликами по иконке в трее.

## Структура проекта

```
src/DynamicHead/Program.cs        точка входа, один экземпляр приложения
src/DynamicHead/AppConfig.cs      настройки и config.json
src/DynamicHead/AudioSwitcher.cs  список устройств и смена устройства по умолчанию
src/DynamicHead/TrayApp.cs        иконка в трее, меню, автозапуск
src/DynamicHead/SettingsForm.cs   окно настроек
src/DynamicHead/assets/           иконки состояний (app-speakers.ico, app-headphones.ico)
tools/build.ps1                   сборка и публикация в dist
tools/gen-icons.ps1               генератор иконок (для сборки не нужен)
```
